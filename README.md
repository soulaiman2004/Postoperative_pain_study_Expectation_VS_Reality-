# Welcome to Postoperative Pain Expectation vs reality study repository

The study aims to evaluate the postoperative pain: patient's expectations , patient's actual pain, and factors related to it in Aleppo university Hospital.
The study used NRS score to evaluate pain expectations and actual patient's pain, also the investigators collected data concerning specifics of each case.
The protocol of this study was discussed between investigators, and the repository is divided into two sections, data prepared for Publishing in publishing scripts,
and analysis scripts used to provide a draft version to the university library in the folder Thesis script.
